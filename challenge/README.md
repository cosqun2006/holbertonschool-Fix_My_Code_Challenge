# Fix My Code Challenge

## Description
This repository contains solutions for the Fix My Code Challenge. The goal of this project is to fix existing codebases and correct logic or syntax bugs across various programming languages.

## Tasks

### 0. FizzBuzz
Fixing the Python implementation of FizzBuzz so that numbers divisible by both 3 and 5 correctly output `FizzBuzz`.

* **Directory:** `challenge`
* **File:** `0-fizzbuzz.py`
